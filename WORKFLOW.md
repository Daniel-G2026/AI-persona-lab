# Workflow and Responsibilities

**Last updated: 2026-10-27.**

## Roles

- **Founder:** selects the working character, references, appearance, publishing goals and final assets; authorizes subscriptions/credits/paid jobs; confirms third-party rights; approves publishing.
- **Claude Code:** maintains the repository, artifacts and automation when tasked; prepares bounded tests with true platform/model costs; preserves all past experiments and reference hashes; documents outcomes, errors and spend.
- **ChatGPT:** helps plan creative direction/prompts and independently reviews uploaded images/videos for identity stability, believable motion and photographic style. A positive review is not proof of real-world repeatability or rights clearance.

## Current tools and decisions

- **Videos:** Higgsfield Genjutsu **Motion Transfer** is the active default for applying **one motion video** to the working blonde character while building a new location. **Object Swap** is an optional same-scene replacement method, not the new-location default. Consult `PRODUCTION_PLAYBOOK.md` for explicit reference-role/@-mention instructions, crop/trim rules and failure cases.
- **Stills:** fal Nano Banana Pro Edit is the current alternative when Higgsfield's still-image features require an extra upgrade. Use numbered reference inputs (or genuine @-tags only if the UI supports them). For profile stills, 1:1, 2K, one test image; check circle crop and viewpoint.
- **Research:** Exp 001–011, 2002 face, A/B variants, prior generated stills and strategy documents remain preserved. No silent conversion of original brown-haired references into blonde identity.
- **Custom training** (LoRA/Soul ID) is **not active**. Require a demonstrated failure that training addresses, a consistent rights-clean dataset, budget approval and quality criteria.

## Spending and recording

1. Monthly cap **$110 USD** across API generations, failed jobs, subscriptions and paid platform plans. **Get approval before new spending.**
2. Reconciled 2026-10-27: Higgsfield plan **$19/month** (270 credits/month) + fal.ai **$6.78** to date (founder-reported from the fal dashboard; repo ledger was ~$6.73) = **$25.78 month-to-date, $84.22 remaining**. Update this figure from actual billing/credit data as spend changes.
3. For each new run, record **date, model/mode, exact reference roles, prompt, source licence, settings, duration/resolution, cost/credits, source/output locations and reviewer verdict**.
4. Save originals and exports separately. Do not assume user chat uploads automatically exist in GitHub or cloud storage. Do not upload third-party copyrighted footage or payments/credentials to the repo.

## Output QA / promotion gates

- **Photo:** same fictional adult, expected outfit and location, correct geometry/lighting, believable skin/hands/reflections, identity stable, no unsupported brand claims, suitable framing for social-media crop.
- **Video:** correct source choreography and temporal timing, no face blend with a motion-source performer, no persistent third-party watermarks/overlays, stable clothing/body and scene, plausible background/camera movement, no obvious artifacts. Review *actual playback* plus extracted frames.
- Track **usable outputs per batch**, cost per usable post, manual repair time and human perceptions; a single successful video is a proof-of-concept only.
- For public release, verify motion/background/track permissions and follow applicable AI-content disclosure rules. Do not represent fictional AI scenes as documented real experiences or endorsements.

## Documentation authority and changes

1. **`PRODUCTION_PLAYBOOK.md`** is the active, practical workflow.
2. **`PRODUCTION_ASSET_REGISTER.md`** lists newer off-repo assets and provenance.
3. **`PROJECT_SPEC.md`** includes original research brief and present character-branch distinction.
4. **`EXPERIMENT_LOG.md`** is chronological research evidence, not a source for latest production-platform UI behavior.
5. **`STRATEGY_REVIEW.md`** and Exp 011 proposals are historical and may be paused/superseded. Preserve them instead of rewriting history.

**Never** rename a provisional artifact canonical, overwrite an approved reference, mark external assets as committed, or spend credits merely because an old proposal listed an estimate.
