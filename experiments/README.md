# Experiments

Each experiment has its own folder (`experiments/NNN-name/`) generated by `scripts/generate_fal.py`.

| File | In git? | Purpose |
|---|---|---|
| `config.json` | yes | Endpoint, exact API params, price, spend cap, approved batches |
| `prompt.txt` | yes | Exact prompt text sent |
| `runs.jsonl` | yes | One line per request: params sent, returned seed, fal request id and headers, size, timings, safety flag, estimated cost, SHA-256 of the file, backup path |
| `contact_sheet.jpg` | yes | Labelled thumbnails of every successful image |
| `review.csv` | yes | Scores per seed against the acceptance checks in `PROMPTS.md` |
| `shortlist/` | yes | Full-resolution copies of shortlisted images only |
| `images/` | **no** | All original PNGs and raw API responses |

## Storing and backing up originals

Originals stay out of GitHub to keep the repo small. They're protected in two ways:

1. **Automatic mirror.** Set `BACKUP_DIR` in `.env` to a folder outside the repo that syncs to the cloud, for example `C:\Users\danya\OneDrive\AI-persona-lab-originals`. The script copies each PNG there as soon as it downloads, keeping the same folder layout.
2. **Integrity check.** `runs.jsonl` (committed) records each original's SHA-256. If a local or backup copy is ever lost or corrupted, the hash identifies the good copy, and the seed + params can regenerate the image.

## Running a batch

```
python scripts/generate_fal.py experiments/001-portrait --seeds 1001-1003 --dry-run
python scripts/generate_fal.py experiments/001-portrait --seeds 1001-1003
```

The script refuses to run if the batch could push recorded spend past `spend_cap_usd`. It skips seeds already generated and stops at the first failed request. Its cost figures are estimates; confirm the actual charges in the fal dashboard and record them in `EXPERIMENT_LOG.md`.

## Credentials

The fal API key lives only in `.env`, which is git-ignored. Never paste it into any committed file.
